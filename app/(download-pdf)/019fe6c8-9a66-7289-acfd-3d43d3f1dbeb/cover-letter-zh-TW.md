Stripe 的 Payments 是全球商業的基礎設施，每年處理數兆美元交易，同時要兼顧全球擴張與系統可靠度、效能——這正是我這幾年職涯持續在做的事：把「金流、財務計算」這類容錯率極低的系統做穩、做對。我目前就在新加坡工作生活，也希望能持續留在這裡，為在地團隊直接貢獻。

在 FundFluent，一間協助香港中小企業媒合資金的金融科技公司，我以契約工程師身分獨自打造了 SME Portal、Partner Portal 與共用 UI Kit 三套正式產品，從技術選型到介面設計全由我一人決定，只在交付里程碑接受檢核——代表我習慣在需求模糊、沒有現成規格時自行釐清邊界並落地。在 AI.Book，我把責任延伸到後端：主導涵蓋 OAuth 登入、購物車與金流串接的 API 設計，從消費端（前端）角度反向定義契約與錯誤處理，確保金流失敗、重試等邊界情境不會卡住使用者。同樣「不把 API 當作別人的問題」的習慣，也延續到我目前在 TikTok 處理廣告財務結算平台、解決 JavaScript 浮點數精度問題以確保金額計算正確的日常工作中。

我在 LINE Taiwan 的 60 人前端團隊裡養成「每一行程式碼合併前都要經另一人審查」的品質習慣，也帶領過 4 人團隊與後端、跨部門利害關係人協調完成 CMS 架構重構；同時也在完全沒有團隊支援的契約案中獨立生存下來。橫跨大型企業嚴謹流程與新創模糊環境的經驗，讓我能快速判斷當下適合的協作節奏。此外我能以中、英、日（JLPT N1）三語溝通，也曾直接向非技術利害關係人說明技術取捨，這對橫跨多國辦公室協作的 Stripe 團隊會是實際的溝通優勢。
